# Battle Island

A Fortnite-inspired browser battle royale prototype built with:

- HTML
- CSS
- JavaScript
- Three.js

## Features

- 3D browser-based world
- First-person player movement
- Mouse look
- Sprinting
- Jumping
- Weapons
- Shooting
- Reloading
- Inventory
- Building
- Enemy players
- Storm system
- Health and shield
- Minimap
- Battle royale HUD

## Controls

| Key | Action |
|---|---|
| W | Move forward |
| A | Move left |
| S | Move backward |
| D | Move right |
| Shift | Sprint |
| Space | Jump |
| Mouse | Look |
| Left Click | Fire |
| R | Reload |
| 1-5 | Select inventory slot |
| E | Use selected item |
| Q | Build wall |
| F | Build floor |
| V | Build ramp |
| B | Build roof |
