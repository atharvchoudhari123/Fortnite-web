# 🎮 Battle Island

A Fortnite-inspired browser battle royale prototype built with:

- HTML
- CSS
- JavaScript
- Three.js
- Node.js
- pnpm

> This is an independent project inspired by the battle-royale genre. It is not affiliated with or endorsed by Epic Games.
